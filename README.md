# Claude Level-Check

Selbsteinschätzung für die Claude-Gruppen (Einsteiger, Medium, Supercracks) bei 24/7 Distribution, TITUS und Partnern.

Seite: https://247dist.github.io/level-check/

- Persönlicher Link: `https://247dist.github.io/level-check/#p-<base64url("Name|E-Mail")>` füllt Name und E-Mail vor.
- Nach „Abschicken & Level ansehen“ geht das Ergebnis per POST an Rodney (`/level-check`). Rodney meldet es per Teams.
- Quelle und Build liegen bei Julius (`Claude-Level-Check.html`, `baue-pages.py`). Hier nur die fertige Seite.
